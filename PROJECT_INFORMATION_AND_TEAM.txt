1. PROJECT OVERVIEW
--------------------------------------------------------------------------------
EJ-SSPI SIMULATOR is a state-of-the-art web-based interactive electronics circuit
simulator designed for diploma engineering students in Electronics & Telecommunication 
Engineering. It combines real-time digital logic gate evaluation, power electronics 
analysis, analog amplifier characterization, and dual-channel DSO/CRO oscilloscope 
emulation in a single unified web platform.

Project Repository Name: logic-gates
Application Title: EJ-SSPI SIMULATOR (Logic & Analog Electronics Simulator)
Tech Stack: React 19, TypeScript 6.0, Vite 8, Web Audio API, Canvas HTML5, Lucide Icons, CSS3 Glassmorphism

4. KEY FUNCTIONALITIES & MODULES
--------------------------------------------------------------------------------

A. DIGITAL LOGIC SIMULATION ENGINE
   - Supports 40+ components across 7 categories:
     1. Inputs & Supplies: Toggle Switch, Push Button, Const High/Low, Clock (Hz), Sine Wave Gen, LDR Sensor, DC Supply, AC Supply, Function Gen.
     2. Logic Gates: BUFFER, NOT, AND, OR, NAND, NOR, XOR, XNOR (2 to 8 inputs).
     3. Discrete Electronics: Resistors, Capacitors, Inductors, Diodes, Zener Diodes, NPN/PNP BJTs, N-MOSFETs.
     4. Integrated Circuits: SR Latch, D/JK/T Flip-Flops, 2:1 MUX, 1:2 DEMUX, Half/Full Adders, 555 Timer, Op-Amp, 4-bit Counter, 2:4 Decoder.
     5. Power Amplifiers: Class A, Class B, Class AB, Class C, Class D.
     6. Outputs & Instruments: Light Bulb, LED Probes, 7-Segment Hex Display, Piezo Buzzer, CRO/DSO Scope Probes.
     7. Annotations: Custom text notes and sticky labels.

B. MSBTE PRACTICAL MANUAL & LABORATORY WORKBENCH
   - Implements full practical manual setup for Analog Electronics (313324) Practical No. 1:
     "Test the performance of single stage Class A power amplifier".
   - Includes:
     * Visual Circuit Diagram (Fig 1.1 schematic: VCC, R1, R2, RL, RE, CE, C1, BJT, Input/Output).
     * Interactive Observation Table (Table 1.1) with live formula calculation:
       - Input Voltage (Vi), Output Voltage (Vo)
       - AC Output Power: Pac = Vo² / (2 * RL)
       - DC Power: Pdc = VCC * ICQ
       - Collector Efficiency: % Efficiency = (Pac / Pdc) * 100
       - Base Current (Ib), Collector Current (Ic), Collector-Emitter Voltage (Vce)
     * Dual Interactive Waveforms:
       - Time-Domain Sine Wave (Input Vi vs Output Vo)
       - Transistor Output Characteristics Curve (Ib vs Ic vs Vce) with dynamic DC Load Line and Q-point.
     * Full MSBTE Practical Questions & Answers:
       1. Low power vs high power transistor datasheets.
       2. Transistor ratings comparison table (VCEO, IC, PD, hFE).
       3. Classification & differentiation of Class A, B, AB, C power amplifiers.

C. DUAL-CHANNEL DSO/CRO OSCILLOSCOPE
   - Emulates real lab cathode-ray & digital storage oscilloscopes.
   - Dual channels (CH1 Input / CH2 Output).
   - Modes: Time-domain, X-Y Lissajous patterns, FFT Harmonic Spectrum Analyzer.
   - Knobs: Volts/Div (10mV to 10V), Time/Div (0.1ms to 50ms), Trigger Level, Channel Inversion.
   - Export: Single-click CSV waveform dataset export for offline MATLAB/Excel analysis.

5. HOW TO RUN AND BUILD THE PROJECT
--------------------------------------------------------------------------------

1. Install Dependencies:
   npm install

2. Start Local Development Server:
   npm run dev
   - Access application at: http://localhost:5173

3. Build Production Bundle:
   npm run build

4. Run Linter:
   npm run lint
